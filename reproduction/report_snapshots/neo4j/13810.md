# Alias shadowing inside COUNT subquery under outer aggregation may trigger internal UnknownError

Reviewed offline evidence snapshot for https://github.com/neo4j/neo4j/issues/13810.

- DBMS/version: Neo4j Community `2026.04.0`
- Maintainer status in frozen audit: confirmed
- Fix status in frozen audit: fixed
- Cached issue source: `data/oracle2_smoke/neo4j_silence6666668_issue_details_20260815.json`
- Frozen audit source: `GitHub_issue_audit_2026-08-25.md`

## Setup

```cypher
MATCH (n) DETACH DELETE n;
CREATE (:Person {name:'Bob', age:25})-[:HAS_DOG]->(:Dog {name:'Rex'});
```

## Minimized trigger

The outer aggregate and the repeated `petName` alias are both part of the
reported boundary.

```cypher
CYPHER 25
MATCH (person:Person)
CALL (person) {
  MATCH (person)-[:HAS_DOG]->(dog:Dog)
  RETURN dog.name AS petName
}
RETURN count(*) AS outerCnt,
       COUNT {
         MATCH (person)-[:HAS_DOG]->(dog:Dog)
         RETURN dog.name AS petName
       } AS numPets
```

## Actual behavior

```text
Neo.DatabaseError.General.UnknownError
Introduced variables have not been computed yet
```

The cached report also records `TransactionStateTransitionException` in the
detailed internal message.

## Expected behavior

The query must not surface an internal error. The corresponding invalid alias
reuse should be rejected with a normal user-facing shadowing error.

## Controls

Renaming the inner alias succeeds with `outerCnt = 1` and `numPets = 1`:

```cypher
CYPHER 25
MATCH (person:Person)
CALL (person) {
  MATCH (person)-[:HAS_DOG]->(dog:Dog)
  RETURN dog.name AS petName
}
RETURN count(*) AS outerCnt,
       COUNT {
         MATCH (person)-[:HAS_DOG]->(dog:Dog)
         RETURN dog.name AS subPet
       } AS numPets
```

Removing the outer aggregate produces the normal shadowing diagnostic instead
of an internal error:

```cypher
CYPHER 25
MATCH (person:Person)
CALL (person) {
  MATCH (person)-[:HAS_DOG]->(dog:Dog)
  RETURN dog.name AS petName
}
RETURN person.name AS name,
       COUNT {
         MATCH (person)-[:HAS_DOG]->(dog:Dog)
         RETURN dog.name AS petName
       } AS numPets
```
