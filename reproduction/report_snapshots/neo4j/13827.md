## Minimized trigger

No graph setup or schema is required. The language-version prefix is explicit.

```cypher
CYPHER 25
RETURN 1 AS y
NEXT
RETURN 1 AS y
UNION
FILTER false
UNWIND [] AS z
RETURN z AS y;
```

## Actual behavior

```text
Neo.DatabaseError.Statement.ExecutionFailed
gql_status: 50N00
Expected: RegularSinglePlannerQuery(...)
Actual: RegularSinglePlannerQuery(...)
```

## Expected behavior

The query should return one row, `y = 1`. The first `UNION` branch contributes
that row; `FILTER false` eliminates the second branch before its empty
`UNWIND`. At minimum, planning must not fail internally.

## Equivalence evidence and preconditions

The paper's auxiliary Cypher 5/25 check assumes a graph-independent, read-only
query; identical output column `y`; bag comparison; no ordering dependency;
and no side effects. Under those conditions the earlier formulation is:

```cypher
CYPHER 5
RETURN 1 AS y
UNION
WITH 2 AS z
WHERE false
UNWIND [] AS z2
RETURN z2 AS y;
```

It returns `y = 1`. The issue also records three Cypher 25 boundary controls:
removing `NEXT`, removing the `UNWIND` following `FILTER false`, or replacing
the standalone filter with `WITH ... WHERE false`; each returns `y = 1`.
